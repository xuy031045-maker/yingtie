01 / 截图

框选即贴

按 Ctrl+Alt+A，拖动选择区域。松开鼠标后，截图出现在原位置。

02 / 参考

随手移动

按住图片拖动，滚轮缩放。鼠标悬停后，可复制、保存或调整透明度。

03 / 收起

双击关闭

用完双击贴图即可关闭。没有点击保存的图片不会自动保存。

从观察到创造

REA、Snipaste 与映贴

这个小工具源于一次对截图软件的探索：先观察现有程序的结构，再围绕自己的需求，独立实现更轻的工作流。

01 / 认识工具

REA 是什么？

REA（Reverse Engineer Anything）是面向 AI 智能体的逆向分析工具项目，可以协助分析程序与二进制文件。它通常需要相应的分析引擎和配置。

访问 REA 官方仓库 ↗
02 / 建立理解

Snipaste 的架构观察

对本机 Snipaste 样本的静态检查发现，它使用 C++ 和 Qt，截图与贴图窗口共享绘图基础。这是结构层面的观察，并未还原原始源码。

03 / 独立实现

映贴是什么？

映贴根据自己的使用需求独立编写，使用 C# 和 Windows Forms，实现截图、置顶贴图和少量必要操作。它没有使用 Snipaste 的源码或程序组件。

04 / 运行环境

在 Windows 上使用

支持 Windows 10/11 x64，依赖 .NET Framework 4.8。运行后常驻通知区域，右键托盘图标可以截图或退出。

关于过程：本次对 Snipaste 的观察使用本机脚本完成；REA 仓库曾下载查看，但没有在该分析中配置或运行 REA 引擎。不同缩放比例的多显示器环境尚未完整实测。
