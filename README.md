# 映贴

<img src="assets/logo.svg" width="96" alt="映贴 Logo：截图边框与悬浮贴纸">

一款轻量的 Windows 截图和桌面贴图工具。按 `Ctrl+Alt+A` 框选截图，图片立即贴在屏幕上；拖动移动、滚轮缩放、双击关闭。悬停时可复制、保存和调整透明度。图片默认不保存到磁盘。

适用于 Windows 10/11 x64 和 .NET Framework 4.8。双击 `映贴.exe` 运行，在通知区域右键图标可退出。`Ctrl+Alt+V` 可贴出剪贴板中的图片。

点击悬停栏的“标注”，可画圆框、方框和箭头；点击“颜色”选择颜色，在图片上拖动绘制。“完成”返回移动模式，Ctrl+Z 撤销上一个标注。复制或保存的图片会包含标注。

详细说明见 [使用说明](使用说明.md)，项目故事与 REA 的介绍见 [介绍页](index.html)。

映贴使用 C# / Windows Forms 独立实现。项目从对本地 Snipaste 程序的静态架构观察获得启发，没有使用其源代码或程序组件。REA 是独立的逆向工程工具；本次静态观察使用本机脚本，未运行 REA 引擎。

源码构建：退出运行中的程序后，在 PowerShell 运行 `./build.ps1`。混合 DPI 多显示器和真实鼠标交互等场景尚未完整实测。

正式构建排除自检代码；需要测试时使用 `./build.ps1 -Test -OutputPath "$env:TEMP\yingtie-check.exe"` 构建独立测试版。
